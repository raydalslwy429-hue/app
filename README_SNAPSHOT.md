## 📌 1. محتويات هذا المجلد الاحتياطي:
يحتوي هذا المجلد على نسخة كاملة ومستقلة لكافة ملفات المشروع البرمجية والإعدادية والأصول البصرية بعد استكمال بناء تطبيق الويب بالكامل وتطبيق الهوية البصرية لمطعم المراسيم:

1. **`src/`:**
   - **`app/actions/capa.ts`:** خادم الإجراءات (Next.js Server Actions) لكافة العمليات الأربع وسيناريوهات الإدارة الثلاثة، مع `revalidatePath` للتحديث اللحظي واختفاء التكليف فور اعتماده.
   - **`app/admin/` (`page.tsx` + `AdminManager.tsx`):** مركز القيادة الإدارية مع 4 تبويبات (فرز وتوجيه، مراجعة واعتماد بالسيناريوهات الثلاثة، السجل العام للبلاغات، وسجل التدقيق).
   - **`app/field/` (`page.tsx` + `FieldQueue.tsx`):** لوحة المنفذين الميدانيين مع تبويبي "معالجة بلاغات جديدة" و "معالجة بلاغات معادة للاستكمال" مع حجب اسم المفتش للحيادية.
   - **`app/inspector/` (`page.tsx` + `InspectorForm.tsx`):** نموذج تسجيل مخالفات الجودة مع الترقيم التسلسلي الصريح (#1, #2...).
   - **`app/login/page.tsx`:** صفحة تسجيل الدخول بالرمز السري 4-Digits وأزرار الدخول السريع لكادر العمل.
   - **`components/Navbar.tsx`:** شريط التنقل العلوي الفاخر بشعار مطعم المراسيم وشعار "يحبها قلبك".
   - **`lib/db.ts` & `lib/auth.ts`:** الاتصال المباشر بقاعدة بيانات Turso السحابية ونظام الجلسات المشفرة عبر ملفات تعريف الارتباط الآمنة (JWT HttpOnly).
   - **`lib/init-db.cjs` & `lib/migrate-cases.cjs`:** سكريبتات تهيئة الجداول الثمانية وترحيل بيانات البلاغات التشغيلية السابقة.
2. **`public/brand/`:**
   - كافة أصول الهوية البصرية المستخرجة بدقة: الشعار الرسمي عالي الدقة، الشعار المفرغ، الشعار الذهبي المتوهج، والشعار الأبيض، بالإضافة إلى صورة الواجهة المعمارية المضيئة.
3. **ملفات التكوين والإعدادات الأساسية:**
   - `package.json` & `package-lock.json`
   - `tsconfig.json`
   - `tailwind.config.ts` (مع لوحة الألوان الخاصة بمطعم المراسيم: `marasim.espresso`, `marasim.gold`, `marasim.burgundy`, `marasim.cream`)
   - `postcss.config.mjs`
   - `next.config.ts`
   - `.env.local` (مفاتيح الربط بقاعدة بيانات Turso السحابية والـ Session Secret).

## ⚡ 3. تعليمات استرجاع أو تشغيل هذه اللقطة:
لتشغيل أو استعادة هذا المشروع في أي وقت:
```bash

# بناء المشروع:
```
